SUPPORTED GRAMMAR

A deliberately small language.

This teaching demo supports function definitions, typed parameters, variable declarations, and return statements. It is not a full C compiler.

Function   → Type ID "(" Parameters ")" Block
Type       → "int" | "float" | "void"
Parameters → Parameter ("," Parameter)* | ε
Parameter  → Type ID
Block      → "{" Statement* "}"
Statement  → "return" Expression ";"
           | "return" ";"
           | Type ID ";"
Expression → Primary (("+"|"-"|"*"|"/") Primary)*
Primary    → ID | NUMBER | "(" Expression ")"
